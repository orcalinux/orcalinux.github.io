# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/JS, no build step. GSAP (+ plugins) loaded from a CDN. Deployed by GitHub Pages from the `main` branch of `orcalinux/orcalinux.github.io`.

## Users

Fellow engineers — embedded, Linux and systems developers — who land here from GitHub, a course repo, or a link, and want to see what orcalinux builds, browse the projects and course material, and jump into the code.

## Product Purpose

Personal portfolio for **orcalinux**, an embedded Linux / systems engineer in Cairo, Egypt. Success = a visiting engineer quickly understands the areas of work (kernel, drivers, bootloaders, firmware updates, system programming, emulators) and clicks through to repositories.

## Positioning

Works close to the hardware and ships the tooling around it: protocol spec + library + CLI + desktop app + simulator (bootwire), not just snippets. Also publishes teaching material (ARM Cortex workshops, embedded Linux diploma, STMicroelectronics system-programming internship).

## Capabilities and Constraints

- Identity: the handle **orcalinux** only. Do not show a real name, email, LinkedIn or other contact. GitHub is the only link out.
- Location: Cairo, Egypt (public on GitHub profile).
- Project facts come from the public GitHub repos; do not invent stars, users, employers or metrics.

## Brand Commitments

- Name/mark: "ORCA LINUX" with `orca@linux` terminal persona.
- Assets: neon banner `assets/banner.webp`, hooded-engineer avatar `assets/avatar.webp` (user-supplied, binding).
- GitHub profile README (`orcalinux/orcalinux`) uses the same neon cyan terminal look; the site should feel like the same identity.

## Evidence on Hand

Public repos (descriptions/topics on GitHub): bootwire, system-programming-under-linux (9★→7★), embedded-linux-diploma, GPS-Distance-Tracking-System, chip8-emulator, c-json, object-pool-library, tiny-language-compiler, IMT ARM Cortex workshop, Microcontroller Architecture & ARM Cortex, Computer-Organization-and-Architecture, Automotive protocols & AUTOSAR, Autonomous-Car. No testimonials, employers, or metrics beyond GitHub stars exist; do not fabricate.

## Product Principles

1. Code first: every project leads to its repo in one click.
2. Show the layer of the stack each project sits on — hardware to userland.
3. Truthful: only facts verifiable on GitHub.
4. Feels like a terminal an engineer would enjoy, never at the cost of reading speed.

## Accessibility & Inclusion

Respect `prefers-reduced-motion` (all GSAP motion off or reduced). Keyboard-navigable, WCAG AA contrast.
