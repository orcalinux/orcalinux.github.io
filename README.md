# orcalinux.github.io

The personal site of **orcalinux** (embedded Linux & systems engineer), built as the manual page `orcalinux(1)`.

Live at [orcalinux.github.io](https://orcalinux.github.io). The GitHub profile README is in [orcalinux/orcalinux](https://github.com/orcalinux/orcalinux).

- Plain HTML + CSS + JS with no build step. GSAP 3.13 is loaded from jsDelivr.
- `index.html` holds the content, `site.css` the styles, `main.js` the behaviour and motion.
- Try the pager keys: `j`/`k`, `/` to search, `1`–`8` to toggle flags, `h` for help.
- `DESIGN.md` documents the design system.
